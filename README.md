<h1>Projeto criador de sites</h1>
<p> Nesse projeto criei uma página do zero em um evento do DevClub onde aprendi várias tecnologias e utilizei elas para fazer esse <a href="https://projetocriadordesites.com.br/">Criador de sites</a> .
  O site consiste no usuário digitar um tipo de negócio(ex:Cafeteria, mercado, lan house, etc.)
  Após clicar em gerar o site gera um site básico apenas com HTML e CSS, onde é apresentado os códigos que foram usados para criar o site em uma tela na esquerda e na direita da página mostra a imagem do site pronto.
  Também implementei responsividade no projeto deixando a página adaptada para celulares.</p>
